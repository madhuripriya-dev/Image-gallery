# Image Gallery

A responsive image gallery built using HTML, CSS, and JavaScript. It includes a lightbox view with previous and next navigation.

## Features

* Responsive image grid
* Click an image to open it in a lightbox
* Previous and next image navigation
* Close button for the lightbox
* Click outside the image to close the lightbox
* Responsive layout for smaller screens

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

image-gallery/
└── index.html

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Click any image to view it in the lightbox.
4. Use the navigation buttons to move between images.
